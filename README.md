DMart Product Data Analysis

An exploratory data analysis project based on a DMart product dataset using Python.

Overview

This project analyzes product-level data from DMart to understand product prices, discounts, categories, brands, quantities, and savings.

The analysis was performed using:

Python

Pandas

NumPy

Matplotlib

Jupyter Notebook

Dataset

The dataset contains 2,980 product records and 9 original columns:

Name

Brand

Price

Discounted Price

Category

Sub-Category

Quantity

Description

BreadCrumbs
